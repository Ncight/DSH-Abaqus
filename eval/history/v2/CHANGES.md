# 指引第二版（v2）相对第一版（v1）的改动

依据：评测 `v1_base`（裸 DSH）、`v1_live`（第一版）、`v2_cand`（本候选），11 道题。

## 第一版暴露的问题

1. **流程过重**。每道题一开始就加载 4～6 个 skill，并把估算、查案例、体检、数据检查、读结果、核查、出图全走一遍。在裸 DSH 也能做对的题上，第一版平均更慢、token 多 1.5～4 倍。
2. **把建模方式限死在 CAE 脚本上**。接触题（钢球压刚性平面）用米建模时接触区单元只有十几微米，接近 CAE 的几何精度，草图、刚性面、网格连续失败，33 次脚本试错后超时。裸 DSH 没有这条限制，它直接用 Python 生成 INP，两次都做对了。
3. **有结果却没交付**（由自动归因流程发现）。接触题中途已得到偏差 0.7% 的结果，但用的是临时作业名，正式作业和结果文件拖到最后，超时时一无所有。
4. **缺两条知识**：轴对称解析刚性面的创建规则；尺寸很小的模型要换单位制。

## 改动

| 改动 | 针对 | 是否经运行验证 |
|---|---|---|
| AGENTS.md 改为分级流程：简单任务照模板直接做，有难点才加载最相关的一两个 skill | 问题 1 | 工作方法 |
| `abq run` 求解后自动给出结果摘要和核查结论（工具改动），流程由 9 步减为 7 步 | 问题 1 | 已实跑 |
| 建模两条路：CAE 脚本，或直接生成 INP；CAE 连续失败时改走后者 | 问题 2 | 工作方法 |
| 新增 skill `abaqus-inp-direct` 和生成器模板 | 问题 2 | 模板算例与解析解一致；刚性单元 + 接触对关键字实跑通过 |
| "同一个错误连续三次没修好就换路" | 问题 2 | 工作方法 |
| "先交付，后优化"；交付物只取自正式作业；结束前核对交付清单 | 问题 3 | 工作方法（来自自动候选 auto1） |
| 接触 skill：轴对称解析刚性面四条规则 | 问题 4 | 已逐条实测（10 种草图） |
| 脚本/材料/接触 skill 与 AGENTS.md：最小单元小于约 0.0001 个模型单位时改用 mm 制 | 问题 4 | 评测题参考解和失败记录中均出现该现象 |
| 脚本 skill：`BaseShell` 草图必须闭合；`findAt` 找不到时返回 None 而不报错；空序列取下标 | 失败记录中的报错 | 已实测 |
| 后处理 skill：接触压力场名带面对后缀、取值是浮点数；接触区尺寸的取法 | 失败记录 | 已实测（自动候选给的写法有两处错误，已更正） |
| 提示表新增 7 条（刚性面/壳特征/特征创建失败、塌缩单元、参数个数、空序列、None） | 失败记录中的报错 | 正则已校验 |

## 评测结果

| 配置 | 通过 | 平均每题耗时 |
|---|---|---|
| 裸 DSH `v1_base` | 22/22 | 477 s |
| 第一版 `v1_live` | 14/15 | 511 s |
| 第二版 `v2_cand` | 13/13 | 372 s（接触题三次平均 742 s，裸 DSH 两次平均 1692 s） |

晋升依据：正确率不低于第一版，保留题不变差，平均每题耗时下降 27%。

## 局限

- 这 11 道题对 Flash 偏易，三种配置的正确率都接近满分，第二版的优势只体现在耗时和 token 上。
- 第二版除接触题外每题只跑了一遍，个别题比裸 DSH 慢（厚壁圆筒、欧拉屈曲、简支板），是否为随机波动未确认。
