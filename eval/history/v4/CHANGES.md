# 候选 v4（2026-11-10 采纳，标签 guidance-v4）

## 依据

1. `eval\report_quality.py` 对基础组、难题组最终汇报的统计（v3，27 次运行）：写了"已知局限"的只有 22%，数字不用科学计数法的 59%；收尾核对交付物平均要 3～6 步。
2. 专业组调优集（d01–d04）在 v3 下 8 次运行全部通过，但步骤记录里有可以省掉的弯路（只看了调优集；保留集 d05–d08 的记录没有用于改指引）：
   - 固结题：初始孔隙比没给或关键字写成 `type=VOIDRATIO`（2 次数据检查失败）；突加荷载放进带 UTOL 的步里（1 次求解失败）。
   - 承载力题：把脚本接口名当关键字写（`*MohrCoulombPlasticity`）。
   - CDP 题：膨胀角填 0（数据检查失败）；为了弄清受拉软化表怎么换算，试算了十几步。
   - 场地反应题：查阻尼器关键字用了 10 步左右。
   - 通用：PowerShell 重定向写出的脚本是 UTF-16，Abaqus 的 Python 读不了；在系统 Python 里 `import odbAccess`；多次调用 `abq odb` 后去读已被重写的 summary.json。

## 验证

- 新 skill 的四个关键字块对应 `eval/skill_checks/gen_geotech_inp.py` 生成的四个输入文件，`chk_geotech_read.py` 把结果与解析值对比（第 19 条验证链）：粘性边界地表峰值 +0.13%、残余 0.15%；固结加载后孔压 100.00/100、Tv = 0.2 时底面孔压 +0.2%、最终沉降 −0.1%；摩尔–库仑（φ = 0）和 Mises（√3·cu）的平面应变强度都是 2cu；CDP 的应力和损伤与按 PEEQT 查表一致。
- 写 skill 时发现并更正了一条原先的说法：CDP 手算与 Abaqus 的差别不是"约 1%"一个数——按塑性应变插值的手算差 0.85%，按开裂应变插值的差 1.93%，原因是 PE33 比 PEEQT 大 0.6%（步长缩小 10 倍后不变，不是积分误差）。
- 19 条验证链全部通过；`skill_snippets.py --calls` 无未验证的接口名。
- skill 里没有实跑支撑的说法已删除或改成实测数字（集中力控制不收敛、法向阻尼系数、步长取周期的 1/50）。

## 要注意的

- v3 的专业组基线是在 `abq odb` 加上"时程在 summary.json 哪个路径"的说明之前跑的，v4 是之后跑的，所以 v4 的提速里有一部分可能来自这处工具改动，两者没有分开测。
- 耗时降幅 16% 刚过 15% 的线，每题只有 2 次运行；调优集的提速可信度高于总体数字（四题里三题下降，d03 不变）。
- 新 skill 的内容来自调优集的题型，保留集里没有固结、粘性边界、CDP 受拉的题，所以"这些内容对没见过的同类题有多大帮助"没有被保留集检验。保留集只说明加了这些内容后别的题没有变差。
- 弹性地基梁（保留集 d07）三种配置都是 1/2，同一项检查失败。按规则没有去看它的失败记录。
