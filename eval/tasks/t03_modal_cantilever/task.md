# 悬臂梁固有频率分析

帮我用 Abaqus 做一根钢悬臂梁的模态分析，我需要它的前三阶固有频率。

## 模型

- 几何：等截面矩形直梁，长 L = 1.0 m，截面宽 b = 0.05 m，截面高 h = 0.10 m。
- 材料：线弹性，弹性模量 E = 2.1e11 Pa，泊松比 ν = 0.3，密度 ρ = 7850 kg/m³。
- 边界条件：一端完全固定（固支），另一端自由。
- 无外载荷、无阻尼，求自由振动的固有频率。
- 这是一根真实的三维梁，要的是它实际的前三阶固有频率（按频率从低到高排，不限振动方向）。
- 坐标系和梁的摆放方向自定。

## 单位

SI 单位制：长度 m，质量 kg，时间 s，力 N，应力 Pa；频率用 Hz。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `modal`，求解完成后当前目录下应有 `modal.odb`。
3. 从计算结果中提取前三阶固有频率，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `frequencies_Hz` | 前三阶固有频率，长度为 3 的数组，从低到高排列 | Hz |

示例格式：`{"frequencies_Hz": [1.0, 2.0, 3.0]}`（数值仅示意格式）。
