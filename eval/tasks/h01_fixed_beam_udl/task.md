# 两端固支梁受均布荷载的静力分析

帮我用 Abaqus 算一根两端固支的混凝土梁，我要跨中最大挠度、支座反力和固定端弯矩。

## 模型

- 几何：直梁，跨度 L = 4 m；矩形截面，宽 0.1 m，高 0.2 m。
- 材料：线弹性，弹性模量 E = 3.0e10 Pa，泊松比 ν = 0.2。
- 边界条件：梁的两端均为固定端（平动和转动全部约束）。
- 载荷：沿全跨作用均布线荷载 q = 1.0e4 N/m，方向沿截面高度方向（即梁绕截面强轴弯曲）。
- 分析类型：线性静力分析（小变形）。
- **要求用梁单元建模**，并且建完整的一跨，不要利用对称性只取半跨。
- 坐标系和梁的摆放方向自定。

## 单位

SI 单位制：长度 m，力 N，应力 Pa，弯矩 N·m。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `fixedbeam`，求解完成后当前目录下应有 `fixedbeam.odb`（ODB 中要保留场输出：位移 U、反力 RF、支座反力矩 RM，我们会直接读 ODB 核对）。
3. 从计算结果中提取下面三个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `max_deflection_m` | 梁的最大挠度（取绝对值） | m |
| `total_reaction_N` | 两端支座沿荷载方向的反力之和（取绝对值） | N |
| `end_moment_Nm` | 固定端的支座弯矩（取绝对值） | N·m |

示例格式：`{"max_deflection_m": 1.23e-3, "total_reaction_N": 4567.0, "end_moment_Nm": 890.0}`（数值仅示意格式）。
