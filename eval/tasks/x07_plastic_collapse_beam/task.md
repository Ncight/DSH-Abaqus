# 简支梁跨中集中力作用下的塑性极限荷载

帮我用 Abaqus 算一根钢梁的塑性极限承载力：简支梁跨中作用一个集中力，材料是理想弹塑性的，我要它的极限荷载（荷载加不上去、挠度持续发展时的那个荷载），顺便给出截面开始屈服时的荷载。

## 模型

- 几何：简支梁，跨度 L = 2 m；实心矩形截面，宽 0.05 m，高 0.10 m（集中力沿截面高度方向作用，即绕强轴弯曲）。
- 材料：弹性模量 E = 2.0e11 Pa，泊松比 ν = 0.3；理想弹塑性（没有强化），屈服应力 σy = 250 MPa。
- 支承：一端固定铰支座，另一端滑动铰支座（可沿梁轴线方向自由滑动）。
- 荷载：跨中作用一个横向集中力，从零开始单调增大，一直加到梁形成塑性铰、丧失承载力为止。
- 坐标约定（请照此建模，我们按这个约定读结果）：梁轴线沿 x，两个支座分别在 x = 0 和 x = 2 m，集中力作用在 x = 1 m 处，方向为 −y；梁轴线位于 y = 0。
- 不考虑自重，按小变形（几何线性）计算即可。用梁单元还是实体单元、网格怎么划分由你决定；也可以利用对称性只建半跨（0 ≤ x ≤ 1 m），但 `result.json` 里要填整根梁的荷载。

## 单位

SI 单位制：长度 m，力 N，应力 Pa。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `collapse`，求解完成后当前目录下应有 `collapse.odb`。作业必须正常算完（状态为 Completed）；靠计算不收敛而中止来估计极限荷载的做法不算数。
3. ODB 中要保留加载全过程的位移 U 和反力 RF 场输出（不要只存最后一帧），最后一帧必须已经处在极限状态：荷载不再增长而挠度仍在发展。具体判据是：在加载分析步最后 15% 的过程里（按分析步时间计），荷载的变化不超过 2%，而跨中挠度至少再增大 5%。我们会直接读 ODB 的反力和位移来核对。
4. 从计算结果中提取下面两个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位），都取正值：

| 键 | 含义 | 单位 |
|---|---|---|
| `collapse_load_N` | 塑性极限荷载：梁所能承受的跨中集中力的最大值 | N |
| `first_yield_load_N` | 截面边缘纤维刚开始屈服时的跨中集中力 | N |

示例格式：`{"collapse_load_N": 12345.0, "first_yield_load_N": 6789.0}`（数值仅示意格式）。
