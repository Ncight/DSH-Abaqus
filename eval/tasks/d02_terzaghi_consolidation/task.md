# 饱和土层一维固结（太沙基问题）

帮我用 Abaqus 做一个流固耦合的一维固结验证算例：饱和土层顶面排水，突然加上大面积堆载，看超静孔压怎么消散、地表怎么沉降。

## 单位制

m–t–s 单位制：长度 m，时间 s，力 kN，应力、模量和孔压 kPa。

## 模型

- 土层：饱和、均质、线弹性土骨架，厚 H = 10 m；弹性模量 E = 10000 kPa，泊松比 ν = 0.3；渗透系数 k = 1e-7 m/s；水的重度 γw = 9.8 kN/m³。土颗粒和孔隙水本身不可压缩。初始孔隙比取 1.0。
- 排水条件：顶面自由排水，底面不透水，侧面不透水。
- 变形条件：大面积堆载，侧向不能变形（一维压缩），底面固定。
- 荷载：顶面作用均布堆载 q = 100 kPa，在 t = 0 时刻瞬时加上，此后保持不变。
- 不考虑土和水的自重（只研究堆载引起的超静孔压）。
- 取一根土柱来代表这一维问题即可。坐标约定（请照此建模，我们按这个约定读结果）：竖向为 y，底面在 y = 0，顶面在 y = 10 m；土柱水平尺寸取 1 m，占据 0 ≤ x ≤ 1 m（三维再加 0 ≤ z ≤ 1 m）。
- 单元类型、网格和时间步长自定。

## 要算的时刻

- 时间因数 Tv = cv·t / H² = 0.2 对应的时刻（cv 为土的一维固结系数，H 为最大排水距离）；
- 固结完成时（一直算到超静孔压基本消散完、沉降稳定为止）。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `consol`，求解完成后当前目录下应有 `consol.odb`（整个过程在同一个作业里）。
3. ODB 里要有孔压 POR 和位移 U 的场输出；Tv = 0.2 对应的那个时刻必须正好有一帧输出（例如让一个分析步在该时刻结束），最后一帧是固结完成的状态。我们会直接读底面点 (0, 0, 0) 的孔压和顶面点 (0, 10, 0) 的竖向位移来核对。
4. 从计算结果中提取下面三个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位），都取正值：

| 键 | 含义 | 单位 |
|---|---|---|
| `excess_pore_pressure_base_kPa` | Tv = 0.2 时刻土层底面的超静孔压 | kPa |
| `settlement_at_tv_m` | Tv = 0.2 时刻的地表沉降 | m |
| `final_settlement_m` | 固结完成时的最终地表沉降 | m |

示例格式：`{"excess_pore_pressure_base_kPa": 12.3, "settlement_at_tv_m": 0.0123, "final_settlement_m": 0.0456}`（数值仅示意格式）。
