# 混凝土损伤塑性（CDP）模型单元受拉加卸载验证

在把 CDP 本构用到整体结构之前，帮我先用 Abaqus 做一个单元级的材料验证：一个混凝土单元单轴受拉，加载—卸载—再加载，看软化段应力、卸载刚度和受拉损伤因子对不对。

## 单位制

m–t–s 单位制：长度 m，力 kN，应力和模量 kPa。

## 材料（混凝土损伤塑性模型）

- 弹性：E0 = 3.0e7 kPa，ν = 0.2。
- 受拉软化（开裂应变 → 应力）：

| 开裂应变 | 0 | 0.0002 | 0.0005 | 0.001 |
|---|---|---|---|---|
| 应力 / kPa | 2000 | 1200 | 600 | 200 |

- 受拉损伤（开裂应变 → 损伤因子 dt）：

| 开裂应变 | 0 | 0.0002 | 0.0005 | 0.001 |
|---|---|---|---|---|
| dt | 0 | 0.3 | 0.6 | 0.85 |

- 塑性参数：膨胀角 36°，偏心率 0.1，fb0/fc0 = 1.16，K = 0.6667。
- 受压硬化数据本算例用不到，取一组合理的数即可（例如屈服应力 21000 kPa 起、峰值 30000 kPa）。

## 模型和加载

- 试件：边长 0.1 m 的立方体，只用一个单元（也可以用 0.1 m × 0.1 m、厚 0.1 m 的平面应力单元）。坐标约定（请照此建模，我们按这个约定读结果）：试件占据 0 ≤ x, y, z ≤ 0.1 m，沿 x 方向单轴受拉。
- 应力状态：单轴应力（侧向可以自由收缩）。
- 加载方式：位移控制，在 x = 0.1 m 的端面施加 x 向位移，x = 0 的端面 x 向固定。按总应变（端面位移 / 0.1 m）计，加载历程为

  0 → 0.0004 → 0.00036 → 0.0008

  即：拉到 0.0004，卸载到 0.00036，再加载到 0.0008。准静态分析。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `cdp`，求解完成后当前目录下应有 `cdp.odb`（整个加载历程在同一个作业里）。
3. ODB 里要有位移 U、应力 S 和受拉损伤因子 DAMAGET 的场输出，并且要足够密：相邻两帧之间总应变的变化不超过 0.00001。我们会直接读 ODB 的应力–应变过程来核对。
4. 从计算结果中提取下面四个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `peak_stress_kPa` | 整个过程中出现的最大拉应力 | kPa |
| `stress_at_0p0004_kPa` | 第一次加载到总应变 0.0004 时的应力 | kPa |
| `unloading_modulus_kPa` | 从 0.0004 卸载到 0.00036 这一段的卸载模量（应力变化 / 应变变化） | kPa |
| `damage_at_end` | 加载结束（总应变 0.0008）时的受拉损伤因子 | 无量纲 |

示例格式：`{"peak_stress_kPa": 1234.0, "stress_at_0p0004_kPa": 567.0, "unloading_modulus_kPa": 1.2e7, "damage_at_end": 0.5}`（数值仅示意格式）。
