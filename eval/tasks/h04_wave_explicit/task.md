# 弹性杆中应力波传播的显式动力分析

帮我用 Abaqus/Explicit 算一个一维应力波算例：一根弹性杆的一端突然被推动，我要看应力波在杆里的传播。

## 模型

- 几何与坐标（**必须按此坐标建模**，杆轴线沿 x 轴）：杆占据 0 ≤ x ≤ 1 m，0 ≤ y ≤ 0.01 m，0 ≤ z ≤ 0.01 m。
- 材料：线弹性，弹性模量 E = 2.0e11 Pa，密度 ρ = 8000 kg/m³，泊松比 ν = 0。
- 初始状态：整根杆静止、无应力。
- 加载：t = 0 时刻起，x = 0 端面突然获得并一直保持恒定速度 1 m/s，方向沿 +x（指向杆内）。速度是瞬间加上的，不是逐渐增加的。
- 边界条件：x = 1 m 端面自由，侧面自由。
- 分析类型：**必须用 Abaqus/Explicit 显式动力分析**，分析总时长 1.5e-4 s。

## 单位

SI 单位制：长度 m，质量 kg，时间 s，力 N，应力 Pa。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `wave`，求解完成后当前目录下应有 `wave.odb`（ODB 中要保留场输出：应力 S，我们会直接读 ODB 核对）。
3. 从计算结果中提取下面三个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `wave_speed_m_s` | 应力波在杆中的传播速度（由计算结果中波前到达不同截面的时刻确定） | m/s |
| `stress_behind_front_Pa` | 波前通过之后稳定段的轴向应力 S11（拉为正、压为负） | Pa |
| `arrival_time_at_mid_s` | 波前到达 x = 0.5 m 截面的时刻，以该处轴向应力的绝对值达到波后稳定值的一半为准 | s |

示例格式：`{"wave_speed_m_s": 1234.0, "stress_behind_front_Pa": 1.23e6, "arrival_time_at_mid_s": 1.23e-4}`（数值和正负号都只是示意格式，应力的正负号请按上面的约定如实填写）。
