# 悬臂梁自由端受横向力的静力分析

帮我用 Abaqus 算一根钢悬臂梁，我要核对自由端挠度和固定端反力。

## 模型

- 几何：等截面矩形直梁，长 L = 1.0 m，截面宽 b = 0.05 m，截面高 h = 0.10 m。
- 材料：线弹性，弹性模量 E = 2.1e11 Pa，泊松比 ν = 0.3。
- 边界条件：一端端面完全固定（固支）。
- 载荷：自由端端面上作用沿截面高度方向的横向力，合力 P = 1000 N。力要分布施加在整个自由端端面上，不要只加在个别节点上。
- 分析类型：线性静力分析（小变形）。
- 用三维实体单元建模，建完整的梁，不要利用对称性只取一半。
- 坐标系和梁的摆放方向自定。

## 单位

SI 单位制：长度 m，力 N，应力 Pa。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `cantilever`，求解完成后当前目录下应有 `cantilever.odb`（ODB 中要保留场输出：位移 U、应力 S、反力 RF，我们会直接读 ODB 核对）。
3. 从计算结果中提取下面两个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `tip_deflection_m` | 自由端沿受力方向的挠度（取绝对值） | m |
| `reaction_force_N` | 固定端沿受力方向的总反力（取绝对值） | N |

示例格式：`{"tip_deflection_m": 1.23e-4, "reaction_force_N": 456.0}`（数值仅示意格式）。
