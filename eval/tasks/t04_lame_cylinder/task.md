# 厚壁圆筒受内压分析

帮我用 Abaqus 算一个受内压的厚壁钢圆筒，我要内、外壁的环向应力和内壁的径向位移。

## 模型

- 几何：厚壁圆筒，内半径 0.1 m，外半径 0.2 m。圆筒很长，取横截面按**平面应变**问题分析（轴向应变为零）。
- 材料：线弹性，弹性模量 E = 2.1e11 Pa，泊松比 ν = 0.3。
- 载荷：内壁作用均匀内压 100 MPa，外壁自由。
- 边界条件：除平面应变条件和消除刚体位移所必需的约束外，不施加其他约束。
- 线性静力分析。可以利用对称性取部分模型；坐标系方向自定。

## 单位

SI 单位制：长度 m，力 N，应力 Pa（注意 100 MPa = 1.0e8 Pa）。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `cylinder`，求解完成后当前目录下应有 `cylinder.odb`（ODB 中要保留场输出：位移 U、应力 S、应变 E、反力 RF，我们会直接读 ODB 核对）。
3. 从计算结果中提取下面三个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `hoop_stress_inner_Pa` | 内壁表面（r = 0.1 m）处的环向应力 | Pa |
| `radial_disp_inner_m` | 内壁的径向位移（相对圆筒轴线向外为正，不含刚体位移） | m |
| `hoop_stress_outer_Pa` | 外壁表面（r = 0.2 m）处的环向应力 | Pa |

示例格式：`{"hoop_stress_inner_Pa": 1.23e8, "radial_disp_inner_m": 1.23e-5, "hoop_stress_outer_Pa": 4.56e7}`（数值仅示意格式）。
