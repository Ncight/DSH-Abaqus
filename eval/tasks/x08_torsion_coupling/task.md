# 实心圆轴受扭：扭转角和最大剪应力

帮我用 Abaqus 算一根实心圆轴的纯扭转：一端固定，另一端加扭矩，我要自由端的扭转角和轴内的最大剪应力。

## 模型

- 几何：实心圆轴，长 L = 0.5 m，直径 d = 0.04 m。
- 材料：线弹性，弹性模量 E = 2.1e11 Pa，泊松比 ν = 0.3。
- 支承：一端的整个端面固定。
- 荷载：另一端作用绕轴线的扭矩 T = 500 N·m。扭矩请通过一个参考点施加：在加载端端面中心处建一个参考点，把它和整个加载端端面耦合起来，扭矩作为集中力矩加在这个参考点上。
- 坐标约定（请照此建模，我们按这个约定读结果）：轴线沿 z，固定端在 z = 0，加载端在 z = 0.5 m，参考点位于 (0, 0, 0.5)；扭矩绕 +z 方向。
- 用三维实体单元建模；单元类型和网格自定。不考虑自重。

## 单位

SI 单位制：长度 m，力 N，力矩 N·m，应力 Pa，转角 rad。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `torsion`，求解完成后当前目录下应有 `torsion.odb`，其中要有位移（含参考点的转角）、应力 S 以及集中荷载/反力的场输出（我们会直接读 ODB 核对）。
3. 从计算结果中提取下面两个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位），都取正值：

| 键 | 含义 | 单位 |
|---|---|---|
| `twist_angle_rad` | 加载端相对固定端的扭转角（参考点绕 z 轴的转角） | rad |
| `max_shear_stress_Pa` | 轴内的最大剪应力（圆轴外表面处的扭转剪应力） | Pa |

示例格式：`{"twist_angle_rad": 0.00123, "max_shear_stress_Pa": 1.23e6}`（数值仅示意格式）。
