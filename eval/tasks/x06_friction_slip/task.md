# 弹性滑块在刚性平面上的摩擦滑动

帮我用 Abaqus 算一个带摩擦的接触算例：一个弹性方块压在刚性平面上，先加竖向压力，再水平推它，直到它整体滑动，我要滑动时的法向力和水平推力。

## 模型

- 滑块：边长 0.1 m 的立方体，线弹性材料，弹性模量 E = 2.0e9 Pa，泊松比 ν = 0.3。
- 平面：水平刚性平面，滑块底面放在平面上，初始时刚好接触（没有间隙，也没有过盈）。
- 接触：滑块底面与刚性平面之间为库仑摩擦，摩擦系数 μ = 0.3；法向为硬接触，允许脱开。
- 坐标约定（请照此建模，我们按这个约定读结果）：刚性平面为 y = 0 平面，滑块在 y > 0 一侧，占据 0 ≤ x ≤ 0.1 m、0 ≤ y ≤ 0.1 m（三维模型再加 0 ≤ z ≤ 0.1 m）；推动方向为 +x。
- 刚性平面请建成带参考点的刚体（解析刚体或离散刚体都可以），参考点的全部自由度固定；我们会读参考点上的反力。
- 加载分两步：
  1. 第一步：在滑块顶面施加竖直向下的均布压力，合力 10 kN；
  2. 第二步：保持压力不变，用位移控制把滑块沿 +x 方向水平推动 1 mm（例如给 x = 0 的那个侧面施加 +x 方向 1 mm 的位移；不要用力来推），此时滑块应已整体滑动。
- 不考虑自重。用二维还是三维模型、单元类型和网格自定（二维模型的面外厚度取 0.1 m）。

## 单位

SI 单位制：长度 m，力 N，应力 Pa。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `slip`，求解完成后当前目录下应有 `slip.odb`，两步加载在同一个作业里。ODB 里要有位移 U、反力 RF 的场输出，接触输出（CSTRESS、CDISP）也请保留（我们会直接读 ODB 核对）。
3. 从第二步结束时刻的结果中提取下面两个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位），都取正值：

| 键 | 含义 | 单位 |
|---|---|---|
| `normal_force_N` | 滑块与刚性平面之间的法向接触合力 | N |
| `sliding_force_N` | 维持滑块滑动所需的水平力（即接触面上切向摩擦力的合力） | N |

示例格式：`{"normal_force_N": 1234.0, "sliding_force_N": 567.0}`（数值仅示意格式）。
