# 水平土层的初始地应力平衡

帮我用 Abaqus 给一个水平成层的土层建立自重作用下的初始地应力场，并做地应力平衡。这是后续动力分析的前置步骤，我要的是“有初始应力、但没有沉降”的平衡状态。

## 单位制（硬性要求）

课题组统一用 **m–t–s 单位制**，这个模型也必须按这套单位建：

- 长度 m，时间 s，质量 t（吨）；
- 力 kN，应力和弹性模量 kPa，密度 t/m³，重力加速度 m/s²。

## 模型

- 几何：水平土层，厚 20 m，水平方向无限延伸。取一个竖向土柱或一个二维条带来代表即可（水平尺寸自定）。
- 材料：线弹性，弹性模量 E = 30000 kPa，泊松比 ν = 0.3，密度 ρ = 1.8 t/m³。
- 载荷：自重，重力加速度 g = 9.8 m/s²，竖直向下。
- 边界条件：侧面为滚轴支承（只约束法向水平位移，竖向可自由滑动）；底面约束竖向位移；地表自由。
- 初始地应力：竖向应力由上覆土重产生；水平应力按静止侧压力系数 K0 = ν/(1−ν)（弹性侧限条件）取。
- 要求：土层在“初始地应力 + 自重”下处于平衡，**平衡后土层不产生沉降**（位移应当是数值零的量级），而应力场保持为上述地应力场。
- 坐标系方向自定；单元类型自定。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `geostatic`，求解完成后当前目录下应有 `geostatic.odb`，它的最后一帧就是地应力平衡后的状态（ODB 中要保留场输出：位移 U、应力 S、反力 RF，我们会直接读 ODB 核对）。
3. 从平衡后的结果中提取下面三个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `max_displacement_m` | 地应力平衡后土层内的最大位移（合位移的最大值） | m |
| `vertical_stress_base_kPa` | 土层底面处的竖向应力（拉为正、压为负） | kPa |
| `horizontal_stress_base_kPa` | 土层底面处的水平应力（拉为正、压为负） | kPa |

示例格式：`{"max_displacement_m": 1.0e-12, "vertical_stress_base_kPa": 12.3, "horizontal_stress_base_kPa": 4.5}`（数值和正负号都只是示意格式，应力的正负号请按上面的约定如实填写）。
