# 一维土柱场地反应：粘性边界上的剪切波输入

帮我用 Abaqus 做一个最基本的一维场地反应验证算例：均质弹性土柱，底部用粘性（Lysmer）人工边界，竖直向上入射的 SH 剪切波从底部输入，我要地表的速度响应。后面的大模型也是这么输入地震动的，所以这个小算例必须做对。

## 单位制

m–t–s 单位制：长度 m，质量 t，时间 s，力 kN，应力和模量 kPa，密度 t/m³。

## 模型

- 土层：均质线弹性，厚 H = 50 m；密度 ρ = 2.0 t/m³，剪切波速 Vs = 200 m/s，泊松比 ν = 0.3。无阻尼。
- 土柱：取一根宽 4 m 的土柱代表水平成层场地（二维平面应变模型，面外厚度 1 m；如果你用三维模型，截面取 4 m × 4 m）。土柱只发生水平剪切运动，同一高程上的土一起运动。
- 坐标约定（请照此建模，我们按这个约定读结果）：竖向为 y，基底在 y = 0，地表在 y = 50 m；土柱占据 0 ≤ x ≤ 4 m（三维再加 0 ≤ z ≤ 4 m）；振动方向为 x。
- 基底边界：粘性人工边界（模拟下卧的同种材料弹性半空间），不能做成固定边界或直接给定基底运动。
- 输入：竖直向上传播的 SH 波，入射波的质点速度时程为 Ricker 子波

  v(t) = A · (1 − 2a) · exp(−a)，其中 a = [π · fc · (t − t0)]²，

  中心频率 fc = 4 Hz，t0 = 0.3 s，峰值 A = 0.1 m/s。波动以等效荷载的形式施加在基底人工边界上。
- 计算总时长 1.5 s（从 t = 0 开始）。不考虑重力。
- 单元类型、网格尺寸、时间积分方法（隐式或显式）和时间步长自定，但要保证波动传播的精度。

## 交付要求

1. 所有工作都在当前目录下完成，模型必须真正提交 Abaqus 求解，不能只给理论值。
2. 作业名（job name）必须是 `site`，求解完成后当前目录下应有 `site.odb`。
3. ODB 里要有速度 V 的场输出（至少包含地表节点），输出间隔不大于 0.005 s，覆盖整个 1.5 s。我们会直接读地表点 (0, 50, 0) 处的水平速度时程来核对。
4. 从计算结果中提取下面三个量，写入当前目录下的 `result.json`。文件内容是一个 JSON 对象，值为数字（不要写成字符串，不要带单位）：

| 键 | 含义 | 单位 |
|---|---|---|
| `peak_surface_velocity_m_s` | 地表水平速度的峰值（绝对值最大值） | m/s |
| `time_of_peak_s` | 出现该峰值的时刻 | s |
| `late_residual_ratio` | t ≥ 1.0 s 之后地表水平速度绝对值的最大值，除以上面的峰值 | 无量纲 |

示例格式：`{"peak_surface_velocity_m_s": 0.123, "time_of_peak_s": 0.45, "late_residual_ratio": 0.012}`（数值仅示意格式）。
