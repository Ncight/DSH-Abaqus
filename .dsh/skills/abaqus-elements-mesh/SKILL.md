# 单元类型与网格密度

网格和单元选错，模型照样能算完，只是数不对。这是最常见的"算完了但结果错"的原因，建模前先按下表定。

## 按问题选单元

| 问题 | 首选 | 可以用 | 不要用 / 注意 |
|---|---|---|---|
| 三维实体，弯曲为主 | `C3D8I`（规则六面体网格）或 `C3D20R` | `C3D8R`，但受弯方向至少 4 层单元 | `C3D8`（全积分线性）受弯会剪切自锁，结果偏硬；`C3D8R` 只有 1–2 层时沙漏，结果偏软 |
| 三维实体，只能划四面体 | `C3D10` | 接触面上用 `C3D10M` | `C3D4` 太硬，应力不可信 |
| 应力集中（孔、缺口、圆角） | 二次单元 `C3D20R` / `CPS8R` / `CPE8R` / `CAX8R` | 线性单元 + 更密的网格 | 线性减缩单元在集中处只给单元中心的值，会低估峰值 |
| 平面应力 / 平面应变 / 轴对称 | `CPS4R`、`CPE4R`、`CAX4R`（一般）；要应力峰值用 8 节点的 `…8R`；弯曲为主用 `CPS4I`/`CPE4I` | 三角形 `CPS6M` 等 | 三节点 `CPS3`/`CPE3`/`CAX3` 只用来过渡 |
| 接触 | 接触面上用线性单元 `C3D8R`/`C3D8I`/`CPE4R`/`CAX4R`，网格足够密 | 四面体用 `C3D10M` | 二次单元（`C3D20`、`C3D10`）的接触压力分布容易有波动，要用就配面-面离散并加密核对 |
| 金属塑性、大变形 | 线性减缩 `C3D8R`/`CPE4R`/`CAX4R` | `C3D8I`（变形不大时） | 二次全积分单元会体积自锁 |
| 接近不可压（ν>0.475，橡胶） | 杂交单元（名字带 `H`，如 `C3D8RH`） | | 普通单元体积自锁 |
| 板壳 | `S4R`（通用），薄厚都行 | 三角形 `S3` 仅过渡 | 厚跨比很小的薄板用实体单元建会很费且易自锁 |
| 梁 | `B31`（考虑剪切变形）；细长梁要对照欧拉梁理论用 `B33` | 二次 `B32` | 梁要定义截面方向，见 `abaqus-beams-shells` |
| 桁架/拉索 | `T3D2`、`T2D2` | | 只有轴力，节点处是铰 |
| 显式动力 | `C3D8R`（加 `hourglassControl=ENHANCED`）、`S4R`、`B31`、`CPE4R`、`CAX4R` | `C3D10M` | 显式里没有 `C3D20` 系列；`elemLibrary=EXPLICIT` |

设置方法：`p.setElementType(regions=(p.cells,), elemTypes=(mesh.ElemType(elemCode=C3D8I, elemLibrary=STANDARD),))`。

## 最低网格密度

- **受弯的实体**：`C3D8R` 沿受弯厚度方向 ≥ 4 层；`C3D8I`/`C3D20R` 1–2 层即可，但长度方向仍要有足够份数（跨度方向 ≥ 20 份较稳妥）。
- **应力集中**：集中处单元边长 ≤ 特征半径（孔半径、圆角半径）的 1/8～1/10，即孔周一圈至少 40～60 个单元；只在集中区局部加密（分区 + `seedEdgeBySize`），远处可以粗。
- **接触**：接触区（接触半宽 a 以内）至少 8～10 个单元；先用解析解估 a，再定单元尺寸。从面网格不比主面粗。
- **模态**：关心的最高阶振型每个半波 ≥ 6 个线性单元（或 3 个二次单元）。
- **波传播（显式）**：单元尺寸 ≤ 最短波长的 1/10，波长 = 波速 / 最高关心频率；沿传播方向单元尺寸尽量均匀。
- **塑性区、裂尖、土体破坏带**：区内至少 5～10 个单元。
- **长宽比**：一般区域 < 5，高应力梯度区 < 2；避免内角 < 45° 或 > 135° 的四边形。

## 判断网格是否收敛

对网格敏感的结果（峰值应力、接触压力、塑性应变、高阶频率）必须做一次加密对比：把关键区域的单元尺寸减半再算一遍，结果变化 < 2%～5% 才算收敛；变化大就继续加密。位移、反力、低阶频率通常收敛得快，应力峰值收敛得慢。

用 `abq sweep` 一条命令完成对比。脚本的参数区写成可由外部覆盖的形式（模板 `template_solid_static.py` 已经这样写）：

```python
import json, os
PARAMS = json.loads(os.environ.get('ABQ_PARAMS', '{}'))
JOB  = str(PARAMS.get('JOB', 'myjob'))        # 扫描时作业名由 abq 指定
SEED = float(PARAMS.get('SEED', 0.01))        # 默认值 = 正式计算用的值
```

然后 `abq sweep model.py --set SEED=0.02,0.01,0.005`：依次生成、求解三个变体，列出单元数、最大位移、应力、传递力、频率、接触压力等以及相邻变体之间的变化百分比。也可以比较单元类型（`--set ELEM=C3D8R,C3D8I`）或其他建模选项。选定方案后，用任务书要求的作业名正式算一遍。

报告里写明：单元类型、关键区域单元尺寸、总单元数、加密前后的对比。

## 结果不对时怀疑什么

| 现象 | 多半原因 |
|---|---|
| 位移比估算小 10% 以上（偏硬） | `C3D8`/`C3D4` 自锁；网格太粗；多约束了自由度 |
| 位移比估算大很多（偏软）、变形呈锯齿 | `C3D8R` 层数太少，沙漏；`abq verify` 里 ALLAE/ALLIE 会超 5% |
| 峰值应力比理论低 | 集中处网格太粗；线性减缩单元取的是单元中心值——看 `abq odb` 里"外推到单元节点"的值，并加密 |
| 固定端/加载点应力特别大且越密越大 | 应力奇异点（尖角、点载荷、刚性约束边缘），那里的峰值没有意义，取离开一个单元以外的值 |
| 接触压力分布锯齿状 | 接触面用了二次单元，或网格太粗 |
| 频率比理论高 | 网格太粗或单元自锁；比理论低很多则可能约束不足或沙漏 |
