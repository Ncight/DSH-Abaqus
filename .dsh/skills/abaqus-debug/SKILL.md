# 排错

原则：**先定位，再修改**。每次只改一处，改完重跑看现象怎么变。不靠放宽收敛容差、加大稳定系数、反复重试来"过关"——那样得到的是一个算完了的错结果。

## 第一步：看 abq 给了什么

`abq run job` 失败时会给出：错误原文、警告分类、`.msg` 末尾的收敛信息（残差/修正量最大的节点和自由度）、针对性的提示。先读完再动。需要再看一次：`abq status job`。

## 按现象排查

### 数据检查就报错（还没开始算）
- 引用了不存在的名字（集合、表面、材料、幅值、实例）：`abq check job.inp` 看名称清单和体检。常见原因是集合建在部件上却按装配级名字引用，或 `getByBoundingBox` 选空了。
- 材料缺属性：动力/模态/重力要密度，塑性要 `*Plastic` 且首行塑性应变为 0。
- 单元没赋截面、截面引用的材料不存在：体检会直接指出。
- 输出变量无效：先只请求 S、U、RF。

### ZERO PIVOT / NUMERICAL SINGULARITY（零主元）
有自由度没被约束。消息里给出节点和自由度号，据此判断：
1. 整个部件能刚体移动：边界条件加错了集合/实例，或部件之间没有 Tie/接触。
2. 接触问题一开始没接触上：改位移加载，或先用小位移建立接触。
3. 梁/壳的转动自由度没约束（绕自身轴线的转动、面外转动）。
4. 二维模型的刚体平动/转动没约束够。
定位办法：加一个只算前 6～10 阶的 `FrequencyStep` 跑一遍，接近 0 Hz 的振型就是没约束住的运动，用 `abq render job.odb --var U --frame 1` 看它是哪个部件在动。

### NEGATIVE EIGENVALUE（负特征值）
- 伴随零主元 → 按上一条处理。
- 屈曲、材料软化、接触脱开时出现属于物理现象：结构在失稳。要越过极值点用弧长法（`StaticRiksStep`）或位移控制。
- 只在个别迭代出现、最后收敛：可接受，但在报告里说明。

### 增量步反复折减（TOO MANY ATTEMPTS / 步长小于最小值）
按顺序查：
1. **量级**：载荷、位移、模量、密度的单位对不对？位移是不是大得离谱？（`abq check` 看参数，`abq units` 对照）
2. **残差最大的位置**在哪：接触面上 → 看 `abaqus-contact`；某个角点/加载点 → 点载荷或约束造成局部塑性或畸变，改成面载荷/分布约束；材料软化区 → 属物理失稳。
3. **几何非线性**：转动或应变较大却没开 `nlgeom=ON`，或开了之后屈曲了。
4. **增量步设置**：`initialInc` 太大（非线性问题从 0.01～0.1 起步），`maxNumInc` 太小。
5. **材料曲线**：`*Plastic` 表不单调、最后一段斜率为 0 之后还在加载（理想塑性下结构达到极限承载力就不会再收敛，这是物理极限）。
还不行就做减法：依次去掉接触（改 Tie）、塑性（改弹性）、几何非线性，各跑一次，看去掉哪一项就能算——问题就在那一项。

### 单元畸变 / 体积为负
- 一开始就报：节点次序或几何有问题，或网格质量极差。
- 算到一半报：变形过大。先查载荷和单位量级；确属大变形就加密、改善初始网格形状，显式里可用自适应网格。

### 显式分析
- 稳定步长极小：有特别小或特别扁的单元，或刚度比例阻尼 β>0，或材料很硬密度很小（单位错）。
- `deformation speed to wave speed` 超限：加载太猛或单位错。
- 能量不平衡：见 `abaqus-dynamics` 的能量表。

### 内存或许可证错误
不是模型问题。等一两分钟重试同一条命令；不要同时提交多个作业。

## 算完了，但结果和估算差得远

按这个顺序逐项排除，每一项都拿出证据（数字），不要凭感觉下结论：

1. **估算本身**对吗？公式适用条件（细长、小变形、平面应力还是平面应变、边界类型）是否和模型一致。
2. **单位**：`abq check` 里的材料参数和 √(E/ρ)、模型尺寸范围、载荷数值，是否同一套单位制。
3. **反力合计 = 施加的总载荷**吗？（`abq odb` 的 RF 合计）不等说明载荷加错了面、加了 n 倍（集中力加在 n 个节点上）、或方向错。
4. **约束**：多约束了（偏硬）还是少约束了（偏软/刚体模态）。`abq render job.inp` 或预览面板看约束位置。
5. **单元与网格**：自锁（偏硬）、沙漏（偏软，`abq verify` 的 ALLAE/ALLIE）、集中处太粗（应力偏低）。换单元类型或加密一次，看结果往哪边动。见 `abaqus-elements-mesh`。
6. **取数**：帧、分析步、位置、积分点还是节点。见 `abaqus-postprocess`。
7. 差 2、4、2π、1000 这类整倍数：对称份数、轴对称整圈、单位换算。

查出原因后修正模型重算；最终仍有差异时，在报告里如实写出差异大小和已排除的原因，不要把数字凑到一致。
